# Vert l’avenir 🌿

## Aperçu du projet

**Vert l’avenir** est un projet de site Web conçu pour un organisme communautaire situé en Montérégie.  
Sa mission est de sensibiliser la population à la protection de l’environnement et de promouvoir des habitudes écoresponsables au quotidien.

Ce site a été pensé pour offrir une plateforme moderne, accessible et facile à mettre à jour, autant pour les citoyens que pour les employés de l’organisme.

---

## Objectifs du site

Le site permet de :

- présenter l’organisme, sa mission et ses valeurs ;
- publier les activités à venir ;
- faciliter les inscriptions en ligne ;
- permettre le recrutement de bénévoles ;
- offrir un espace de dons en ligne ;
- diffuser des nouvelles et articles liés à l’environnement ;
- simplifier la gestion du contenu grâce à une interface d’administration.

---

## Public cible

Le site s’adresse principalement à :

- la population locale de la Montérégie ;
- les citoyens intéressés par l’écologie ;
- les bénévoles ;
- les partenaires et commanditaires ;
- les employés de l’organisme ;
- une partie du public anglophone.

---

## Structure du site

Le site est divisé en plusieurs sections principales :

- Accueil
- Nos activités
- Galerie
- Équipe et bénévoles
- Partenaires et commanditaires
- Calendrier
- Inscription / bénévolat
- Dons / paiements
- Blog / actualités
- Contact / accès
- Administration
- Statistiques

---

## Description des pages

### Accueil
La page d’accueil présente l’organisme, sa mission, ses valeurs et les services offerts.  
Elle sert aussi de point d’entrée vers les autres sections du site.

### Nos activités
Cette page présente les activités à venir organisées par Vert l’avenir.  
Elle sert à informer les visiteurs sur les événements disponibles, comme le jardinage urbain, les ateliers écologiques, les collectes de déchets électroniques et les activités de bénévolat.

### Galerie
La galerie affiche des photos et vidéos des activités passées.  
Elle sert à montrer l’implication de l’organisme dans la communauté et à rendre le site plus vivant.

### Équipe et bénévoles
Cette page présente les membres de l’équipe ainsi qu’une liste fictive de bénévoles.  
Elle sert à humaniser l’organisme et à valoriser les personnes impliquées.

### Partenaires et commanditaires
Cette section affiche les partenaires de Vert l’avenir.  
Elle sert à reconnaître les collaborations importantes et à renforcer la crédibilité de l’organisme.

### Calendrier
Le calendrier présente les activités à venir dans une vue organisée.  
Il sert à planifier les événements et peut être modifié par les employés.

### Inscription / bénévolat
Cette page contient un formulaire permettant de s’inscrire à une activité ou de devenir bénévole.  
Elle sert à faciliter la participation citoyenne.

### Dons / paiements
Cette section permet aux visiteurs de faire un don en ligne.  
Elle sert à soutenir financièrement l’organisme avec différentes méthodes de paiement.

### Blog / actualités
Cette page permet de publier des nouvelles, articles et contenus de vulgarisation scientifique.  
Elle sert à informer la communauté et à garder le site actif.

### Contact / accès
Cette page contient les coordonnées complètes, les heures d’ouverture et l’adresse de l’organisme.  
Elle sert à permettre aux visiteurs de communiquer facilement avec Vert l’avenir ou de se rendre sur place.

### Administration
L’espace administrateur permet aux employés d’ajouter ou modifier du contenu sans connaissances techniques avancées.  
Cette section sert à garder le site autonome, évolutif et facile à maintenir.

### Statistiques
La page des statistiques affiche des données comme :
- le nombre total d’utilisateurs ;
- le nombre de paiements ;
- le nombre d’événements ;
- la répartition des rôles ;
- la répartition des types d’événements ;
- le montant total des dons reçus.

Elle sert à offrir une vue d’ensemble rapide pour la gestion interne.

## Structure technique

Le projet suit une architecture **MVC** :

- **Models** : représentent les données comme les utilisateurs, événements, paiements et adresses ;
- **Views** : affichent les pages du site ;
- **Controllers** : gèrent la logique entre les données et l’interface.

Cette structure permet de garder le projet organisé, plus facile à développer et plus simple à maintenir.

## Installation et lancement

1. Cloner le projet :
```bash
git clone <url-du-repo>
```

2. Ouvrir le projet dans Visual Studio

3. Configurer la base de données dans `appsettings.json`

4. Appliquer les migrations :
```bash
Update-Database
```

5. Lancer le projet
